## 遇到的一些问题记录
1. <html lang="">
lang 应该写什么 
1. nested 相同方向的嵌套swiper，当切换到子swiper时停止父swiper的切换。
1. updateOnWindowResize 默认当窗口(window) 尺寸发生变化时，比如屏幕旋转，Swiper会更新和重新计算(update和breakpoints等)。
